Wi-Fi di sekitar perangkat Anda

Halaman ini menampilkan daftar Wi-Fi yang tertangkap oleh perangkat Anda sendiri — bukan Wi-Fi milik pemilik dashboard.

Kenapa perlu satu langkah? Browser (Chrome, Safari, Edge) sengaja tidak diizinkan memindai daftar Wi-Fi. Ini aturan Google dan Apple demi privasi, bukan kekurangan situs ini. Jadi perlu bantuan aplikasi kecil di perangkat Anda.

1. Nama perangkat

Supaya Anda dan pemilik dashboard bisa membedakan perangkat.

Tidak perlu daftar akun.

2. Jalankan sekali di perangkat ini

Pilih perangkat Anda. Setelah selesai, daftar Wi-Fi muncul di bawah otomatis.

  1. Pasang dua aplikasi dari F-Droid (bukan Play Store):
    Termux Termux:API
  2. Buka Termux, tempel perintah ini, tekan Enter: 
    memuat…
  3. Kalau diminta izin, pilih Allow untuk Lokasi pada Termux:API, dan nyalakan GPS di HP.
  4. Biarkan Termux tetap terbuka. Data terkirim tiap 30 detik.
  1. Unduh agent:
    Unduh agent (ZIP)
  2. Ekstrak, lalu buat file agent-config.txt di folder yang sama dengan isi ini: 
    memuat…
  3. Klik dua kali agent.bat. Biarkan jendelanya terbuka.
  1. Buka Terminal, tempel perintah ini, tekan Enter: 
    memuat…
  2. Linux butuh nmcli. macOS butuh perintah airport (bisa tidak tersedia di macOS Sonoma ke atas).

3. Hasil

Menunggu data pertama dari perangkat Anda…

Menunggu data… Halaman ini memeriksa otomatis tiap 5 detik.

Data yang dikirim hanya: nama Wi-Fi (SSID), sinyal, channel, band, dan jenis keamanan. Tidak ada isi trafik, kata sandi, atau data pribadi. Data disimpan di memori server dan hilang saat server dimatikan.
Hanya pindai jaringan yang Anda miliki atau yang Anda punya izin untuk memantau.
