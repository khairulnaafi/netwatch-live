DNS OBSERVER

Aktivitas domain di jaringan Anda

DNS logger mencatat nama domain yang diminta perangkat — bukan isi halaman atau data HTTPS. Aktifkan hanya di jaringan sendiri dan beri tahu penggunanya.

Memuat… —

Port 5354 · upstream 8.8.8.8

Cara menangkap aktivitas (opsional)

Butuh satu langkah di router atau perangkat yang Anda kelola.

  1. 1
    Aktifkan DNS logger

    Server akan mendengarkan permintaan DNS di port 5354.

  2. 2
    Arahkan DNS perangkat ke IP komputer ini

    Di router: set DNS server ke IP-LAN. Banyak router hanya menerima port 53 — ubah port di config.json dan jalankan sebagai admin bila perlu. Private DNS Android tidak mendukung port kustom.

  3. 3
    Lihat domain muncul

    Feed di bawah terisi otomatis. Untuk HTTPS, hanya domain yang terlihat — path dan konten tetap terenkripsi.

Catatan: fitur ini hanya mencatat domain dari perangkat yang memakai DNS logger ini, bukan isi HTTPS, dan tidak bisa membaca trafik Wi-Fi orang lain dari luar jaringan. Port 5354 dipakai karena port 5353 sudah dipakai mDNS Windows. Uji dengan node tools/dns-query.js example.com.
